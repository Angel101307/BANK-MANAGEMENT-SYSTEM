# Project Statement

## Project Title
Bank Management System

## Problem Statement
Managing basic banking operations manually can be time-consuming and may lead to errors. The purpose of this project is to develop a simple Python-based Bank Management System that allows users to perform common banking operations through a console-based interface.

## Scope
The system focuses on basic banking operations such as:
- Checking bank balance
- Depositing money
- Withdrawing money
- Transferring money
- Viewing transaction history
- Reporting customer issues
- Validating user inputs

## Target Users
The system is designed as an educational banking application for users who want to understand and perform basic banking operations through a simple console-based system.

## High-Level Features
1. Account creation and validation
2. Balance checking
3. Money deposit
4. Money withdrawal
5. Money transfer
6. Transaction history
7. Issue reporting
8. Input validation and error handling

## Objective
The main objective of this project is to demonstrate the use of Python programming concepts such as functions, classes, modules, conditional statements, loops, input validation, exception handling, and modular programming.

## Expected Outcome
The system should allow users to perform basic banking operations through a structured and easy-to-use console interface while handling invalid inputs appropriately.
