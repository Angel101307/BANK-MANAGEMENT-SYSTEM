# BANK-MANAGEMENT-SYSTEM
A Python-based Bank Management System for managing account balance, deposits, withdrawals, money transfers, transaction history, and customer issue reporting.

## Project Overview
The Bank Management System is a Python-based console application developed to perform basic banking operations. It provides a simple and user-friendly interface for managing an account and carrying out common banking transactions.

## Features
- Check bank balance
- Deposit money
- Withdraw money
- Transfer money
- View transaction history
- Report an issue
- Validate account number
- Validate mobile number
- Validate transaction amount
- Handle invalid inputs

## Technologies Used
- Python
- Python IDLE
- GitHub

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `main.py` using Python IDLE.
4. Run the program using Run → Run Module or press F5.
5. Enter the required account details.
6. Select an option from the banking menu.

## Testing
The project includes `test_bank.py` for testing:
- Account number validation
- Mobile number validation
- Account creation
Run `test_bank.py` using Python IDLE.

Expected output:
